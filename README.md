### Purpose

The purpose of this repository is to enshrine fundamental backend programming paradigms, architectures, execution patterns, communication protocols for the purpose of learning and disseminating knowledge to others. 



#### Structure
The structure of this repository is a set of nodejs applications and shell scripts for backend services demonstrating various concepts, each folder represents a learning domain or concept and all curls, backend code are housed in each, with a small writeup README explaining usage, and tradeoffs of the demonstrated concept when applied to production systems
